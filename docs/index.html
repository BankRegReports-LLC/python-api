BankRegReports Python SDK

Clean, validated, cross-source regulatory data on every US bank, credit union, and holding company, at a fraction of the cost of enterprise data platforms. In three lines of Python.

$ pip install bankregreports

Why BankRegReports

US bank regulatory data is entirely public. Getting it into a form you can actually use is a different problem entirely.

The problem with "free" regulatory data

The US banking system produces an enormous volume of public data. Every federally insured institution files quarterly Call Reports with more than 2,000 line items. The UBPR distills those into pre-computed ratios. The NCUA collects equivalent 5300 Call Reports from 4,800+ credit unions. The Federal Reserve maintains organizational structure and Y-9C holding company filings. The FDIC tracks branches, failures, and enforcement history. SEC EDGAR contains XBRL financial facts, insider disclosures, proxy statements, and 8-K event filings for every publicly registered bank.

All of it is free. Almost none of it is usable out of the box.

What you find The real problem
Cryptic MDRM codes Call Report data arrives keyed by codes like RCON2170 and RIAD4107. The data dictionary is a separate 400-page PDF. Codes are silently retired across quarters with no changelog in the data.
Unit chaos Values appear in at least four conventions across sources: whole dollars, thousands of dollars, ratios as decimals, ratios as integers. The NCUA 5300 stores interest rates as integers (×100 basis-point encoding). Miss this and your rate analysis is off by a factor of 100.
Schema drift without notice The FFIEC adds, removes, and redefines schedules each quarter. A bulk download from Q1 may have different column names, nullability, and value semantics than Q2. No migration guide. No deprecation warning. You find out when the pipeline breaks.
Silent revisions Institutions refile quarterly. Prior values are silently overwritten in published bulk files. If you downloaded Q3 data in October and again in January, you may have two different values for the same cell with no restatement flag.
ID fragmentation A single bank appears under at least four identifiers: Federal Reserve RSSD ID, FDIC certificate number, OCC charter number, and one or more SEC CIK numbers. Joining data across sources requires building and maintaining your own crosswalk, and that crosswalk has gaps.
Calculation mismatches Computing NIM from raw Call Report data looks simple until you discover the FFIEC uses a specific annualization methodology with an average-earning-assets denominator spread across 12 MDRM items. Getting a number that agrees with the published UBPR (the regulatory benchmark) requires knowing all of it.

The expensive alternative

The financial data industry has known about this problem for decades. The solution was a class of enterprise providers who do the cleaning internally and resell the processed result:

Provider Approximate cost Access model
Leading bank data platforms $20K–$200K+/year Enterprise contract, multi-year
Financial terminal providers $20K–$30K+/seat/year Terminal or data feed subscription
Credit & risk data vendors Enterprise pricing Sales process required
Specialized structured finance platforms Enterprise pricing Opaque quotes, long contracts

These services solve the problem: the data is clean, the calculations are correct, the sources are linked. But the pricing was designed for large institutions, rating agencies, and investment banks. Not for community banks doing their own analysis, fintech startups building bank-adjacent products, academics studying the banking system, or analysts who need to answer one question before Friday.

The result is a market with nothing in the middle: raw data that takes months of engineering to make usable, or enterprise subscriptions that require a procurement cycle and a budget most organizations can't justify.

Why we built this

BankRegReports was built by people who ran into this gap firsthand, tasked with a bank analysis project and discovering that the only options were to spend months wrestling with free government bulk files or sign an enterprise contract for access to data that is, at its origin, entirely public.

The team behind BankRegReports has been in ALCO. Been through regulatory exams. Built bank models, constructed liquidity stress tests, sat in credit review committees, and done the kind of analysis that examiners and board members ask for. We knew what the data was supposed to look like and what the calculations were supposed to produce. Getting from a raw Call Report download to a defensible ROA calculation required solving a dozen intermediate problems that no one had documented clearly.

So we built the platform we needed. Everything the data industry has known was missing: the quality and accuracy of enterprise data products, delivered through a modern REST API with a Python SDK that returns pandas DataFrames, at a price point that makes bank regulatory data accessible to anyone who needs it.

Quick Start

Three lines to pull CET1 ratios for every Georgia bank above $500M in assets.

import bankregreports
brr = bankregreports.BankReg("brr_xxx")   # or set BANKREG_API_TOKEN env var
df  = brr.screener(state="GA", min_assets=500_000)
print(df[["legal_name", "total_assets", "cet1_ratio"]].head(10))

Line by line

Line What it does
import bankregreports Imports the SDK package. All public classes and helpers are exposed at the top-level namespace.
BankReg("brr_xxx") Creates an authenticated client. Pass your API token directly or omit it to read from the BANKREG_API_TOKEN environment variable.
brr.screener(...) Queries the screener endpoint with the given filters and returns a pandas DataFrame (or list of dicts if pandas is not installed).
df[...].head(10) Standard pandas column selection and row limit. Works identically to any other DataFrame.

Installation

The SDK requires Python 3.10 or later. The only mandatory runtime dependency is requests.

Core install

$ pip install bankregreports

Installs the SDK with its single hard dependency (requests>=2.28). List-returning methods return list[dict].

With pandas integration

$ pip install "bankregreports[pandas]"

Adds pandas as a dependency and enables automatic DataFrame output from all list-returning methods. The pandas extra is recommended for interactive analysis in Jupyter notebooks or any workflow that uses DataFrame operations.

Virtual environment (recommended)

$ python -m venv .venv && source .venv/bin/activate && pip install "bankregreports[pandas]"
✓
Output format
List-returning methods return a pandas.DataFrame by default, which needs the pandas extra. Pass as_dataframe=False to any method to get the decoded JSON instead, with no pandas dependency.

Authentication

All authenticated endpoints use bearer token authentication. Tokens are prefixed brr_ and are issued per account at bankregreports.com/api/.

Method 1: Constructor argument

import bankregreports
brr = bankregreports.BankReg("brr_xxx")

Method 2: Environment variable

import os
import bankregreports

# Set in your shell or .env file:
# export BANKREG_API_TOKEN=brr_xxx

brr = bankregreports.BankReg()   # reads BANKREG_API_TOKEN automatically
ⓘ
Security recommendation
Never hard-code tokens in source files that are committed to version control. Use environment variables, a secrets manager, or a .env file that is listed in .gitignore.

API Reference

All methods are called on a BankReg client instance. RSSD 37 (Bank of Hancock County) is used as the example institution throughout this reference; JPMorgan Chase Bank is RSSD 852218.

Banks: Directory & Snapshot
brr.bank_search_index()
Returns the full directory of all FDIC-insured banks. Each record includes institution name, RSSD ID, FDIC certificate number, state, and asset tier classification. 
df = brr.bank_search_index()
brr.bank(rssd_id)
Returns a complete snapshot of a single bank: financials, capital ratios, asset quality metrics, earnings data, and peer context in a single response. 
snap = brr.bank(rssd_id=37)  # Bank of Hancock County
brr.bank_trends(rssd_id, quarters=12)
Returns the quarterly time series of the bank's key metrics, one row per quarter. Defaults to the last 12 quarters. 
trends = brr.bank_trends(rssd_id=37, quarters=8)
brr.bank_deep_dive(rssd_id)
Returns the full regulatory financial profile of a bank, covering capital adequacy, liquidity ratios, asset quality indicators, and earnings metrics in depth. 
deep = brr.bank_deep_dive(rssd_id=37)
brr.bank_profile(rssd_id)
Returns identity and organizational data for a bank: charter class, regulatory agency, executive officers, physical addresses, and the full holding company chain from NIC. 
profile = brr.bank_profile(rssd_id=37)
brr.bank_compare(rssd_ids)
Returns a side-by-side comparison table for up to 10 banks across all key financial ratios. Useful for competitive benchmarking or due diligence. 
cmp = brr.bank_compare(rssd_ids=[37, 852218, 413208])
brr.banks(state, tier, q, sort, limit, offset)
The directory of FDIC-insured banks. Filter by state, asset tier, or a name search q. To compare a known list of banks side by side, use bank_compare(). 
ga = brr.banks(state="GA", limit=100)

brr.bank_deposits(rssd_id)

dep = brr.bank_deposits(rssd_id=37)
brr.bank_securities(rssd_id)
Returns the investment securities portfolio breakdown by held-to-maturity (HTM) and available-for-sale (AFS) categories, including accumulated other comprehensive income (AOCI) and unrealized gains and losses. 
sec = brr.bank_securities(rssd_id=37)
brr.loan_portfolio(rssd_id)
Returns loan book detail segmented by category: commercial real estate (CRE), commercial and industrial (C&I), consumer loans, residential mortgage, and construction and land development. 
loans = brr.loan_portfolio(rssd_id=37)
brr.bank_hmda(rssd_id)
Returns Home Mortgage Disclosure Act (HMDA) data for the bank: mortgage origination volumes, approval and denial rates, and demographic breakdowns by year. 
hmda = brr.bank_hmda(rssd_id=37)

brr.bank_structure(rssd_id)
Returns the NIC organizational structure for a bank, including its parent holding company chain, direct and indirect subsidiaries, and ownership percentages at each level. 
struct = brr.bank_structure(rssd_id=37)
brr.bank_events(rssd_id)
Returns regulatory lifecycle events for a bank: charter grants, mergers and acquisitions, legal name changes, conversions between charter types, and branch openings or closures. 
evts = brr.bank_events(rssd_id=37)
brr.bank_history(rssd_id)
Returns the full historical record from the NIC database, including predecessor institutions, historical names, and the complete chain of corporate lineage back to the institution's founding. 
hist = brr.bank_history(rssd_id=37)
brr.bank_fry15(rssd_id)
Returns FR Y-15 systemic importance indicators for institutions that file the report. Includes the eight GSIB indicator categories used to assess global systemic importance.

Banks: Scores & Peers
brr.scorecard(rssd_id)
Returns the BRR proprietary composite score for the bank, broken into five sub-dimensions: safety, growth, credit quality, efficiency, and value. Scores range from 0 to 100 within each asset tier peer group. 
sc = brr.scorecard(rssd_id=37)
brr.ranks(rssd_id)
Returns national peer group percentile ranks for more than 20 financial metrics, letting you see where the bank stands relative to institutions of similar size and charter type. 
r = brr.ranks(rssd_id=37)
brr.peer_ranking(rssd_id, metric)
Returns the bank's percentile rank on one metric (for example "cet1_ratio", "roa" or "npl_ratio") within its peer group.

brr.peers(rssd_id)
Returns the peer group definition for a bank: which asset tier bucket it belongs to, charter class, primary operating region, and business model classification used by the BRR scoring engine.

brr.peer_comparison(rssd_id)
Returns a full peer comparison table showing the bank's value for every available metric alongside the peer group median, enabling direct benchmarking across all dimensions. 
pc = brr.peer_comparison(rssd_id=37)
Banks: Branches
brr.branches(rssd_id, source, rollup, as_map)
Returns branch network data from FDIC Summary of Deposits (banks) or NCUA branch files (credit unions).
  • source: "fdic" (default) or "ncua"
  • rollup=True: aggregates branch counts by state and county rather than returning individual branch records
  • as_map=True: returns a GeoJSON FeatureCollection suitable for mapping 
# Individual branch records
br = brr.branches(rssd_id=37)

# GeoJSON for mapping
geo = brr.branches(rssd_id=37, as_map=True)

# State-level rollup
rollup = brr.branches(rssd_id=37, rollup=True)

Screeners
brr.screener(**kwargs)
Filters all FDIC-insured banks by financial criteria. All parameters are optional and can be combined.
  • state: Two-letter state code, e.g. "GA"
  • min_assets / max_assets: Total assets in thousands of dollars
  • min_cet1: Minimum CET1 capital ratio (percent)
  • max_npa: Maximum non-performing asset ratio (percent)
  • asset_tier: Asset size tier: "community", "midsize", "large", "gsib"
  • charter: Charter class code, e.g. "N" (national bank)
  • region: Federal Reserve district code or region name 
df = brr.screener(state="GA", min_assets=500_000, min_cet1=12.0)
brr.ma_screener(**kwargs)
Filters banks by M&A attractiveness signals: price-to-book ratio, tangible book value, excess capital levels, geographic footprint, and strategic fit indicators. Useful for identifying acquisition targets. 
targets = brr.ma_screener(state="TX", max_assets=2_000_000)
brr.loan_concentration(**kwargs)
Identifies banks with elevated concentration in specific loan categories relative to risk-based capital. Use min_cre_pct to find banks above the supervisory CRE concentration threshold (300% of risk-based capital). 
cre = brr.loan_concentration(min_cre_pct=300)
brr.growth_screener(**kwargs)
Filters banks by revenue and asset growth trajectories. Supports filtering on year-over-year asset growth, loan growth, deposit growth, and net interest income growth. 
growers = brr.growth_screener(min_asset_growth_yoy=15.0, state="FL")

Rates & Yield Curve
brr.rates(kind)
Returns a historical rate series. Supported kind values:
  • "fed_funds": Effective federal funds rate
  • "sofr": Secured Overnight Financing Rate
  • "prime": US bank prime lending rate
  • "t2y": 2-year Treasury constant maturity yield
  • "t10y": 10-year Treasury constant maturity yield
  • "mortgage_30y": 30-year fixed mortgage rate (Freddie Mac)
  • "cd_national": FDIC national average CD rate
  • "savings_national": FDIC national average savings rate 
ff = brr.rates(kind="fed_funds")
t10 = brr.rates(kind="t10y")
brr.yield_curve(latest, tenor, start_date, end_date)
Returns the US Treasury yield curve in long form, one row per date and tenor. Pass latest=True for the current curve, tenor="Y10" for one tenor's daily series, and ISO dates in start_date / end_date to bound the range. 
yc = brr.yield_curve(latest=True)
ten_year = brr.yield_curve(tenor="Y10", start_date="2024-01-01")

Reference & Catalog
brr.metrics()
Returns the full BRR metric catalog: every BRR-M- canonical code with its human-readable name, definition, unit type, MDRM source code, and calculation notes.

brr.reference(slug, as_of, limit)
Returns reference data. With no slug it lists the available tables; slug="states", "regulators" and so on return that table. Pass an MDRM item code as the slug to get its definition, resolved for the as_of date. 
defn = brr.reference(slug="RCON2170")
brr.datasets_catalog()
Returns a machine-readable catalog of all available dataset endpoints, including endpoint paths, required parameters, and response schemas. 
dc = brr.datasets_catalog()
brr.list_datasets()
Returns a human-readable list of all named reference datasets available through the dataset() method, with short descriptions of each. 
ds = brr.list_datasets()
brr.dataset(name)
Fetches a named reference dataset by name. Available datasets include "charter_codes", "asset_tiers", "regulatory_agencies", "state_codes", and others returned by list_datasets(). 
charters = brr.dataset(name="charter_codes")
brr.healthz()
Performs a lightweight health check against the API. Returns {"status": "ok"} when the API is reachable and operational. This endpoint is public and does not require authentication. 
brr.healthz()
Pagination
brr.pages(name, page_size=50, max_records=None, **kwargs)
Returns a lazy iterator that pages through any paginated dataset. Pass the dataset name as the first argument and any filter parameters as keyword arguments. Each iteration yields one page as a DataFrame, or as decoded JSON with as_dataframe=False. 
for page in brr.pages("screener", page_size=200, state="TX"):
    process(page)

Error Handling

All SDK errors inherit from BankRegError. Import the specific exception classes from the top-level bankregreports namespace or from bankregreports.exceptions.

Exception hierarchy

BankRegError
Base exception. Raised for any API or network error not covered by a more specific subclass.
Attributes: status_code (int), message (str), response_body (dict | None)
AuthenticationError
401
The API token is missing, malformed, or has been revoked. Check that BANKREG_API_TOKEN is set correctly or that the token passed to the constructor is valid.
ForbiddenError
403
The token is valid but the account does not have permission to access this endpoint. Verify the subscription tier required for the endpoint you are calling.
NotFoundError
404
The requested institution, filing, or resource does not exist in the BRR database. Verify the RSSD ID, CU number, accession number, or other identifier.
RateLimitError
429
The request rate limit for the account tier has been exceeded. The SDK will respect the Retry-After header on automatic retries (see retries configuration). On final failure, this exception is raised.
Extra attribute: retry_after (int): seconds to wait before retrying
UpgradeRequiredError
402
The endpoint or feature requires a higher subscription tier than the current account holds. Upgrade at bankregreports.com/api/.
ServerError
5xx
An upstream API error occurred. The SDK will automatically retry on 5xx responses according to the retries configuration with exponential backoff.

Full error handling example

import bankregreports
from bankregreports import (
    AuthenticationError,
    ForbiddenError,
    NotFoundError,
    RateLimitError,
    UpgradeRequiredError,
    BankRegError,
)

brr = bankregreports.BankReg("brr_xxx")

try:
    snap = brr.bank(rssd_id=99999999)
except NotFoundError:
    print("Bank not found")
except RateLimitError as e:
    print(f"Rate limited, retry after {e.retry_after}s")
except UpgradeRequiredError:
    print("Upgrade to Pro to access this endpoint")
except AuthenticationError:
    print("Check your API token")
except BankRegError as e:
    print(f"API error {e.status_code}: {e.message}")

Pagination

The pages() iterator handles cursor-based pagination transparently. Pass the unbound method reference and any filter keyword arguments; the iterator fetches the next cursor on each call automatically. 

import bankregreports
brr = bankregreports.BankReg("brr_xxx")

# Iterate all Texas banks page by page (memory-efficient)
for page in brr.pages("screener", page_size=200, state="TX"):
    for bank in page:
        print(bank["legal_name"], bank["total_assets"])

# Collect all pages into a single flat list
# Note: use only for small-to-moderate result sets
all_banks = [
    row
    for page in brr.pages(brr.bank_search_index)
    for row in page
]
print(f"Total banks loaded: {len(all_banks)}")
⚠
Memory consideration
Collecting all pages into a single list using the list comprehension pattern above loads every result into memory at once. For full bank directories (4,000+ institutions) this is manageable. For high-cardinality endpoints, process row by row within the per-page loop instead.

Configuration

All configuration is accepted through the BankReg constructor or through environment variables. Constructor arguments take precedence over environment variables.

Constructor signature

BankReg(
    token=None,
    base_url=None,
    api_version="v1",
    timeout=30.0,
    max_retries=3,
    session=None,
)

Constructor parameters

Parameter Type Default Description
token str | None None API key (brr_…). When None, falls back to the BANKREG_API_TOKEN environment variable. Public-tier datasets work without a key.
base_url str | None https://api.bankregreports.com API origin, without the /api/v1 path. Falls back to BANKREG_API_BASE_URL, then the production host. You should not need to change it.
api_version str "v1" URL path version segment.
timeout float 30.0 Per-request timeout in seconds. A timeout raises APITimeoutError.
max_retries int 3 Automatic retries for GET requests on 429 and 5xx responses and on network errors, with exponential backoff (1, 2, 4 seconds). A 429 waits for the server's Retry-After, capped at 30 seconds per wait. POST, PATCH, PUT and DELETE are never retried.
session requests.Session | None None A pre-configured requests.Session to reuse connections or add proxies.

Environment variables

Variable Maps to Description
BANKREG_API_TOKEN token API key. The constructor token argument takes precedence.
BANKREG_API_BASE_URL base_url API origin override. The constructor base_url argument takes precedence.

Configuration examples

import bankregreports

# Explicit options
brr = bankregreports.BankReg(
    "brr_xxx",
    timeout=60,
    max_retries=5,
)

# Everything from the environment: export BANKREG_API_TOKEN=brr_xxx
brr = bankregreports.BankReg()

# Raw JSON instead of DataFrames, per call
rows = brr.screener(state="GA", as_dataframe=False)
